# 🚀 Data Analysis Team 1 Projects

Welcome to the central repository for **Team 1**'s data analysis projects, completed as part of the **Digital Egypt Pioneers Initiative (DEPI) - Junior Data Analysis Track**.

## 📂 Repository Structure
This repository is divided into two main sections:

### 1. 🛒 Mini Project: Retail Sales End-to-End Analytics
A comprehensive analysis of retail sales data to track financial performance, build a relational data model, and evaluate KPIs using Power BI. 
*(Navigate to the `Mini_Project (Retail sales)` folder for full details and deliverables).*

### 2. 📊 Final Project: Superstore Sales Data Analysis
An in-depth, end-to-end analysis of the Superstore dataset, focusing on profitability, sales trends, and regional performance using Python, SQL, and advanced DAX.
*(Navigate to the `Final_Project (Store sales analysis)` folder to see our ongoing work).*

## 🛠️ Tech Stack & Tools
- **Data Cleaning & Preparation:** Power BI, Python
- **Database & Querying:** SQL (SSMS)
- **Data Modeling & Visualization:** Power BI (DAX, Power Query, Row-Level Security)
- **Version Control & Collaboration:** GitHub
