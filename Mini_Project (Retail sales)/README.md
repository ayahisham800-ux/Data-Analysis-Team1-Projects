# 📊 Retail Sales End-to-End Analytics

## 📝 Project Overview
This mini-project focuses on analyzing retail sales data to uncover business insights, track financial performance, and evaluate KPIs using an end-to-end data analytics pipeline.

## 🎯 Key Objectives
- Clean and preprocess raw dataset.
- Build a relational data model (Star Schema).
- Create advanced DAX measures for financial KPIs.
- Design an interactive and dynamic Power BI dashboard.
- Implement Row-Level Security (RLS) and publish to Power BI Service.

## 🛠️ Tools & Technologies
- **Data Cleaning:** Power BI
- **Data Modeling & Calculations:** Power BI (Power Query, DAX)
- **Visualization & Deployment:** Power BI Desktop, Power BI Service, Power BI App
